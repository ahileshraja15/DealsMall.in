# DealsMall – Full Stack Web Application

## Project Overview
DealsMall is a full stack web application developed using frontend and backend technologies.
The frontend manages the user interface, while the backend handles server logic and APIs.
Both parts work together using a client–server architecture.

## Tech Stack

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Node.js
- Express.js
- npm

## Frontend
The frontend is responsible for displaying the UI, collecting user input,
and sending requests to the backend server.

## Backend
The backend runs on Node.js and Express.js.
It handles API requests, processes data, and sends responses to the frontend.

## How to Run the Project

### Backend
1. Open terminal
2. Go to backend folder:
   cd firstlack/backend
3. Install dependencies:
   npm install
4. Start server:
   npm start
   or
   nodemon

### Frontend
1. Open frontend folder
2. Open index.html in a browser
   or use Live Server in VS Code
